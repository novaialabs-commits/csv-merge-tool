複数のCSVを1つにまとめて重複を削除する方法（Excel・無料ツール）

2026年10月13日公開

月ごと・店舗ごとに分かれたCSVを1つの表にまとめたい。期間が重なっていて、同じ注文が2回入ってしまう。そんなときの手順です。

前提：列名をそろえる

結合する前に、各CSVの列名・列数・列の並び・文字コードを確認してください。下で紹介する方法は、どちらも同じ構造のファイルをまとめる用途に向いています。列名が違ったり列の位置がずれたりすると、意図しない列への取り込みや欠損、エラーの原因になります。結合するCSVだけを専用のフォルダーに入れ、バックアップや別形式のファイルが混ざらないようにしましょう。

方法1：ExcelのPower Queryでフォルダーごとまとめる

  1. まとめたいCSVだけを1つのフォルダーに入れる
  2. データ タブ → データの取得 → ファイルから → フォルダーから でそのフォルダーを選ぶ
  3. 結合 → データの結合と変換 を選ぶ。文字化けする場合は、この画面の 元のファイル で文字コードを選び直す
  4. Power Query エディターで結合結果・列名・データ型を確認する
  5. 重複を判定する列（例：注文番号）を選ぶ。すべての列が一致する行だけを消したい場合は、すべての列を選ぶ
  6. ホーム → 行の削除 → 重複の削除
  7. 閉じて読み込む

次の月のCSVをフォルダーに追加したら、データ → すべて更新 で結果が更新されます。注意：Power Queryの 重複の削除 では、重複した行のうちどの行が残るかは保証されていません（並べ替えておいても、その順序が保たれるとは限りません）。例えば同じ顧客IDに古い住所と新しい住所がある場合、新しい方が残るとは限りません。「最新の行を残す」などの条件がある場合は、単純な重複の削除ではなく、条件に合う行を選ぶ処理が必要です。

Windows版Excelを想定しています。バージョンや更新状況によってメニューの表示が異なる場合があります。

方法2：無料のブラウザツールでまとめる

Power Queryの設定が面倒なときや、1回だけまとめたいときは、CSV・Excel 結合と重複削除ツールが使えます。

  1. ファイルを複数選ぶ（CSV・xlsx、UTF-8／Shift_JISは自動判定）
  2. 重複を判定する列を選ぶ（選ばなければ、すべての列が一致する行を重複とみなします）
  3. 結合して重複を削除 → 読み込み件数・削除件数・結果件数が表示される。重複した行は、先に読み込んだファイル・上にある行が残ります
  4. 結果と、削除した重複行をそれぞれCSVでダウンロード

処理はブラウザの中だけで行われ、ファイルの内容はどこにも送信されません。1万行・重複100件の架空データで、重複削除の処理が0.4秒ほどで終わることを確認しています（2026年10月、Chrome、一般的なノートパソコン。読み込み時間は含みません）。作業前に元ファイルをコピーし、出力結果の件数と内容を確認してください。

必ず件数を確かめる

結合と重複削除だけを行った場合は、「取り込んだデータ行数（見出し行を除く）＝ 重複削除後の行数 ＋ 削除した行数」になっているか確認してください。合わない場合は、読み込みエラーや空行の扱い、意図しない絞り込みを確認します。件数が合っていても内容が正しいとは限らないため、代表的な行の値も確かめましょう。

制作・確認について：本記事の原案は生成AI（Claude）を使用して作成し、Excel・Power Queryに関する技術的な記述を別の生成AI（ChatGPT）でMicrosoft公式資料と照合しました。実際の画面表示や利用できる機能は、Excelのバージョン・OS・更新状況によって異なる場合があります。
列名がファイルごとに違う、どの行を残すかの条件があるなど、ツールで対応できない結合はココナラ（有料・見積り相談制）で受け付けています。
